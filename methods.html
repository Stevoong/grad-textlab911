Methods guide

연구방법론·연구 모형 가이드

지도학생 논문에서 실제로 쓰인 설계를 바탕으로, 자주 묻는 연구방법 질문에 미리 답할 수 있도록 정리한 학습용 페이지입니다. 일반 방법론 설명은 교과서 수준의 공통 지식이며, 특정 학생 논문에 대한 서술은 공개된 논문 요약·연구모형 자료에 근거합니다. 개인정보·미공개 원자료는 포함하지 않습니다.

변수 역할 가설 세우기 설문·측정 분석법 텍스트 마이닝 FAQ

01 · Variables

변수 역할 독립·매개·조절·종속·통제

양적 경로모형에서는 각 개념이 모형 안에서 맡은 역할이 분명해야 합니다. 아래 라벨은 본 사이트 연구모형 다이어그램과 동일한 색·용어를 씁니다.

독립변수

Independent (IV)

연구자가 원인으로 두는 변수입니다. 처치·자극·지각된 특성 등이 여기에 해당합니다.

매개변수

Mediator

IV가 DV에 영향을 미치는 과정을 설명합니다. “왜·어떻게”에 답합니다.

조절변수

Moderator

경로의 강도·방향이 언제·누구에게 달라지는지를 나타냅니다. 상호작용 효과입니다.

종속변수

Dependent (DV)

최종적으로 설명·예측하려는 결과 변수입니다.

통제변수

Controls

관심 경로 외에 결과를 흔들 수 있어 통계적으로 고정하는 변수입니다. 가설의 “주인공”은 아닙니다.

미니 모형 ① — 매개 (IV → Med → DV)

가장 흔한 형태입니다. 예: 설득 전략 → 위험 인식 → 보호행동 의도.

실제 논문 예: 후옌(PROCESS Model 4), 꾸옥, 장자함(긍정적 감정 매개).

미니 모형 ② — 조절이 있는 경로

조절변수는 보통 경로 “옆”에서 해당 화살표의 크기를 바꿉니다.

실제 논문 예: 위만 — 회고적 자극→공감 경로에 대한 사회적 영향(조절). (이중태도·이원신뢰 SEM 제안 모형)

미니 모형 ③ — 통제변수

통제변수는 다이어그램 하단에 점선 박스로 모아 둡니다. 역할 라벨은 「통제변수」입니다.

실제 논문 예: 후옌(한국어 능력·VP 경험·디지털 리터러시·성별·나이), 응옥(인구통계·AI 경험 등).

역할은 이론·가설이 정합니다. 같은 개념이라도 연구 질문에 따라 IV가 되기도 하고 Med가 되기도 합니다. 사이트 다이어그램의 역할 표기는 각 논문 출처의 역할 정의를 따릅니다.

02 · Hypotheses

가설 세우기

가설은 “변수 A가 커지면 변수 B가 …”처럼 검증 가능한 문장입니다. 경로모형에서는 보통 화살표 하나(또는 조절·매개 묶음)가 가설 하나에 대응합니다.

  • 직접효과: IV → DV (예: 숏폼 특성 → 행동의도).
  • 매개효과: IV → Med → DV (간접경로가 유의한지).
  • 조절효과: 경로가 조절변수 수준에 따라 달라지는지.
  • 방향: (+)·(−)를 이론에 맞게 미리 밝힙니다.
좋은 가설피해야 할 예
「위험 인식이 높을수록 개인정보 보호행동 의도가 높아질 것이다(+).」「보이스피싱과 보호행동은 관련이 있을 것이다.」(방향·변수가 모호)
경로·측정 개념이 모형 그림과 1:1로 대응측정하지 않은 개념을 가설에만 등장

경로 라벨(H1, H2a…)은 지도학생 논문 연구모형 SVG에 그대로 표시됩니다. 예: 위만 H1–H8, 장자함 H1a–d·H2a–d·H3·H4.

03 · Survey & measurement

설문 설계·측정

본 랩의 많은 양적 논문이 온라인 설문(또는 시나리오·자극 노출 후 설문)을 사용합니다. 핵심은 조작적 정의와 신뢰도·타당도입니다.

  1. 이론에서 개념 정의 → 기존 척도 검토(번역·역번역·파일럿).
  2. 문항은 보통 Likert 다문항. 구성개념당 문항 수를 밝힙니다.
  3. 자극이 있으면(영상·시나리오) 노출 절차를 방법에 명시합니다.
  4. 수집 후 Cronbach’s α, 탐색적/확인적 요인분석, 공통방법편의 점검을 보고합니다.

설문·SEM

보누(위버스·250명), 꾸인(미디어 풍부성·252명), 장자함(숏폼·503명) 등.

시나리오 설문

후옌 — 보이스피싱 설득 전략 시나리오 후 위험 인식·보호의도.

자극 후 회귀

응옥 — 생성형 AI 뉴스 영상 인식 → 수용 태도(위계적 회귀).

실험·집단 비교

응웬 — 고/저 서사 광고 집단, PROCESS Model 6.

상세 절차·표본은 각 항목의 연구방법론 블록을 보세요.

04 · Analysis

분석법 가이드

논문에 실제로 등장한 분석만 예시로 연결합니다. 도구 이름(SPSS, AMOS, PROCESS 등)은 해당 논문 방법 서술에 따른 것입니다.

구조방정식모형(SEM)

측정모형(CFA)과 구조경로를 함께 추정합니다. 적합도(χ², CFI, RMSEA 등)와 경로 계수를 보고합니다.

예: 보누, 장자함(AMOS), 꾸인, 위만(제안).

회귀·위계적 회귀

DV 하나에 여러 IV를 넣을 때, 또는 통제변수를 1단계에 넣는 위계적 회귀에 씁니다.

예: 닷(다중회귀), 응옥(위계적 회귀).

매개·조절 (PROCESS)

Hayes PROCESS로 Bootstrap 간접효과를 보는 경우가 많습니다. Model 4는 단순 매개, Model 6은 연쇄 매개입니다.

예: 후옌·꾸옥·장자함(Model 4), 응웬(Model 6).

질적·사례·AIGC 비교

설문 대신 사례 비교·시청각 언어 분석으로 제작·표현 특성을 읽습니다.

예: 번반석 — Seedance·Runway·실사 영상 비교.

텍스트 마이닝

댓글·리뷰 등 비정형 텍스트를 빈도·감정·네트워크·군집으로 요약합니다. 다음 장에서 자세히 다룹니다.

예: 투짱, 트엉, 느꾸잉.

05 · Text mining

텍스트 마이닝 챕터 랩 실무

Text Lab. 911에서 반복해 온 댓글·담론 분석 흐름을 정리합니다. 뼈대는 유튜브·공식 채널 댓글 분석 논문(특히 〈폭싹 속았수다〉 예고편 한·영 댓글 비교인 투짱, 〈선재 업고 튀어〉 공식 댓글인 트엉, 베트남 TikTok 댓글인 느꾸잉)의 절차에 맞춥니다. 양적 SEM 제안 모형인 위만과는 설계가 다르니, 텍스트 분석 과제를 할 때는 아래 TM 사례를 기준으로 하세요.

1) 데이터 종류

  • 유튜브 댓글 — 예고편·공식 클립 등 (투짱: Netflix 공식 YT 예고편 1–4막; 트엉: 유튜브·네이버TV 공식 댓글).
  • 숏폼·SNS 댓글 — 느꾸잉: 연애 공감 숏폼 37개의 베트남어 댓글.
  • 리뷰·기사·커뮤니티 글 — 연구 질문에 따라 가능. 수집 가능 범위·이용약관·저작권을 먼저 확인합니다.

2) 수집 방법

  • YouTube Data API — 공개된 동영상·댓글 스레드를 API 할당량·할당된 필드 범위 안에서 수집할 수 있습니다. API 키·할당량·댓글 비활성 영상·삭제·검열된 댓글은 수집되지 않습니다. (투짱 방법: YouTube API로 한·영 댓글 수집.)
  • 플랫폼이 제공하는 공식 export·연구용 도구, 또는 연구윤리·약관에 맞는 수집 스크립트. 로그인 벽 우회·비공개 데이터 무단 수집은 하지 않습니다.
  • 수집 로그: 영상 ID, 수집 시점, 언어, 원문 건수를 방법에 남깁니다.

3) 전처리

  • 정제: URL·중복·스팸·이모지 정책·초단문 처리.
  • 형태소·토큰화: 언어별 분석기(한국어는 형태소 분석, 베트남어·영어는 해당 토크나이저).
  • 불용어·사용자 사전: 고유명사·작품명 보존.
  • 다국어: 언어 식별 후 분리 분석 또는 비교 설계(투짱: 한·영 비교; 느꾸잉: 베트남어).
  • 트엉 사례: Textom을 이용한 전처리 파이프라인.

4) 분석 종류

키워드 빈도·TF-IDF

무엇을 자주·특징적으로 말했는지. 작품·막·언어별 비교의 출발점.

감성·감정 분석

극성 또는 다범주 감정. 느꾸잉은 GoEmotions 기반 감정 분석 후 공출현을 봅니다. (특정 상용 감정사전 성능을 단정하지 않습니다.)

토픽 모델링 (LDA 등)

댓글 묶음의 잠재 주제를 요약할 때. 주제 수·해석 가능성을 함께 보고합니다.

의미연결망·군집

공출현 네트워크, 군집으로 ‘말의 덩어리’를 시각화(투짱·트엉·느꾸잉).

비교 분석

언어권·막(act)·콘텐츠 유형별 차이. 투짱의 국내외 반응 비교가 전형입니다.

5) 결과 해석·시각화

상위 키워드 표, 워드클라우드(보조), 네트워크 그래프, 막대·히트맵으로 “차이”를 보여 줍니다. 해석은 수치만 나열하지 말고 연구 질문(예: 신파성 반응, 시간이동 서사 감정, 반복 시청 표현)에 다시 연결합니다.

6) 윤리

  • 공개 댓글을 쓰더라도 개인 식별 정보(ID·실명·연락처)는 비식별·삭제합니다.
  • 공격·민감 표현 인용 시 최소·필요 범위만.
  • 플랫폼 약관·연구윤리 심의 요건을 따릅니다.

7) 도구 옵션 — Text Lab. 911

랩의 텍스트 분석 플랫폼 Text Lab. 911 (textlab911.com)을 전처리·탐색 분석 보조 도구로 활용할 수 있습니다. 논문의 최종 분석 파이프라인(API 수집, Textom, GoEmotions 등)은 각 논문 방법에 기재된 도구를 기준으로 하세요.
